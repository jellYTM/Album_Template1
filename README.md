# Web Album Template (Album_Template1)

Google Apps Script (GAS) を利用した、シンプルなオンライン写真アルバムのテンプレートプロジェクトです。
スクロールに応じた画像のフェードインアニメーションや、紙吹雪・バルーンの演出が含まれています。

## ファイル構成

- **code.js**: WebアプリケーションとしてHTMLを配信するためのGASスクリプト（`doGet`関数）。
- **main.html**: アルバムのメインとなるHTML/CSS/JavaScriptファイル。画像やメッセージの表示、アニメーション処理を含みます。
- **appsscript.json**: Google Apps Scriptのマニフェストファイル。
- **.clasp.json**: ローカル環境からGASにデプロイするためのclasp設定ファイル。

## 特徴

- **レスポンシブデザイン**: スマートフォンやタブレットでも綺麗に表示されるように設計されています。
- **スクロールアニメーション**: 画面を下にスクロールすると、画像とメッセージがフェードインしながら表示されます。
- **特別なエフェクト**: タイトル部分での紙吹雪（Confetti）アニメーションや、背景のフワフワ浮かぶバルーンのエフェクトが実装されています。

## 使い方

1. プロジェクトをGoogle Apps Scriptにプッシュします（claspを利用）。
2. Webアプリケーションとしてデプロイします。
3. `main.html` 内の画像URL（`<img src="...">`）やテキストを編集して、オリジナルのアルバムを作成してください。
